Eye Tracking for Ad Effectiveness: Weekly Project Report

Week 1 Week 2 Week 3 Week 4 Week 5 Week 6 Week 7 Week 8

Week 1: Defining the Project Scope

Objective: Define project goals, review literature, and identify tools and methods for analyzing visual content in advertisements.

  • Defined the scope of the project focusing on eye-tracking relevance.
  • Reviewed prior studies on visual perception, image segmentation, and social media ad performance.
  • Outlined the research plan and project timeline.
  • Tools identified: Python, OpenCV, CNNs, and social media scraping frameworks.

Conclusion: A clear roadmap for the next stages was created, ensuring a strong foundation.

Week 2: Data Collection and Initial Analysis

Objective: Gather image data from social platforms and perform a preliminary analysis of visual features linked to user interaction.

  • Scraped ads and images from Instagram and Twitter.
  • Tagging included brightness, text presence, and layout structure.
  • Basic visual trends were identified: brighter colors and centered layouts saw better engagement.

Conclusion: Data is prepared for advanced feature extraction in upcoming weeks.

Week 3: Extraneous Sources and Image Mining

Objective: Apply CNN-based image mining to extract features and identify patterns in high/low engagement ads.

  • Used pre-trained models (VGG16, ResNet50) to analyze imagery.
  • Found face presence and color intensity influenced user attention.
  • t-SNE visualizations showed strong clustering between high- and low-engagement posts.

Conclusion: Feature-rich datasets prepared for training predictive models in Week 4.

Week 4: Building the First Model and Initial Testing

Objective: Train a baseline model to predict engagement levels from visual inputs.

  • Implemented Logistic Regression and Decision Tree models.
  • Initial results: Decision Tree performed better (68% accuracy).
  • Facial presence and color saturation were the most predictive features.

Conclusion: Baseline set; future iterations will improve using advanced methods.

Week 5: Model Optimization and Parameter Tuning

Objective: Boost accuracy using ensemble learning and hyperparameter optimization.

  • Tested Random Forest and XGBoost models with GridSearchCV.
  • XGBoost reached 83% accuracy on validation sets.
  • Improved model's ability to predict high-engagement ads.

Conclusion: Optimized models are ready for interface integration.

Week 6: Model Integration with User Interface

Objective: Build a prototype interface that integrates the model for user testing.

  • Flask app developed with image upload and prediction feedback.
  • Users can view image effectiveness and get suggestions to improve it (color balance, focus).

Conclusion: A functional demo is live and ready for user feedback in Week 7.

Week 7: System Testing and Feedback

Objective: Conduct user testing and refine the interface based on feedback.

  • 10 users tested the demo and provided input.
  • Added visual guides and more intuitive feedback display based on their suggestions.

Conclusion: Interface improved; testing validated project usefulness for marketers and designers.

Week 8: Documentation and Finalization

Objective: Compile all work, generate documentation, and deliver the final report and presentation.

  • Created documentation for models, interface, and data sources.
  • Final presentation includes visuals, model graphs, and use case demos.
  • Delivered ZIP with code, HTML interface, and final report PDFs.

Conclusion: The project is now complete, offering a working example of using eye-tracking insights for ad optimization.
